I am a software engineer and solutions architect focused on building comprehensive technological ecosystems. As founder of **Abacore S.A.S.**, my work centers on transforming complex business requirements into robust, scalable software architectures — spanning web, mobile, and native desktop applications.

I approach each project by selecting the right tool for the job rather than defaulting to a fixed stack. ## Featured Work

### AVTech — Enterprise Management Platform

A full-scale enterprise system developed for **Avellano S.A.S.**, designed to unify critical business operations under a single, cohesive platform. The architecture covers multiple interdependent modules, each built for production reliability.

| Module | Description |
|---|---|
| Logistics & Delivery | Real-time order tracking and route management with live map integration |
| Access Control | Biometric authentication, QR scanning, and visitor management |
| Inventory Management | Stock control, product lifecycle, and supplier coordination |
| Billing & Payments | Invoice generation, OpenPay integration (PSE, card, QR) |
| Notifications | WhatsApp Business API bot flows and WebSocket real-time alerts |
| Security | Multi-factor authentication, role-based access control, session management |

**Stack:** React · TypeScript · Node.js · PostgreSQL · Docker · WebSockets · WhatsApp API · Google Maps API · OpenPay

### Abacore S.A.S. — Corporate Platform

The digital presence and client-facing platform for the software studio I founded. Built to communicate our engineering capabilities and support business development through a clean, conversion-focused interface.

**Stack:** HTML5 · CSS3 · JavaScript · Node.js

### Native Desktop Applications

Development of standalone desktop applications using **JavaFX** with **MySQL** backends, including automated deployment pipelines via advanced scripting. These projects targeted environments where web delivery was not viable, requiring full offline capability and native OS integration.

## Approach

Software is not merely a technical deliverable — it is the mechanism through which a business operates, grows, and competes. I build with that perspective in mind.

Every system I design prioritizes three non-negotiables: **reliability**, so it works when it matters most; **security**, because trust is not optional; and **clarity**, because software that cannot be understood cannot be maintained.

I am equally comfortable in a whiteboard architecture session, a code review, or a client presentation. That range — from the technical depth of implementation to the strategic framing of a solution — is what allows me to take projects from concept to production with consistency.
